# ebook_app

A Ebook app made in Flutter with using Cubit and Api..

## Features

* Show OnBoarding
* Show Categores
* Show Books By Category
* Show Best seller
* Search For Books
* Select by category
* Show Book Details 
* Show Favorite 
* Light and Dark Theme
* Add and Remove Favorite

## Installation

### 1. Clone the repo

```
git clone https://github.com/MahmoudDabour1/ebook_app.git
cd ebook_app
```

### 2. Run pub get

```
flutter pub get
```
### 3. Run the app

```
flutter run
```
